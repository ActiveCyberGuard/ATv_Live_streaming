📡 ক্যামেরা চালু করুন

কোন ফ্রেমে ক্যামেরা দিতে চান? স্প্লিট মোডে আলাদা আলাদা ক্যামেরা ব্যবহার করুন।

স্প্লিট ফ্রেম ক্যামেরা:

📷 ফ্রেম ক্যামেরা সেট করুন

ফ্রেমে ক্লিক করে সেই ফ্রেমে ক্যামেরা বা কন্টেন্ট সেট করুন

🚀 YouTube / Facebook লাইভ

আপনার Stream Key দিন এবং নিচের নির্দেশনা অনুসরণ করুন।

📋 YouTube এ লাইভ করার ধাপসমূহ:
১. studio.youtube.com এ যান
২. উপরে "লাইভ শুরু করুন" ক্লিক করুন
৩. "Stream" ট্যাব বেছে নিন
৪. Stream Key কপি করুন → নিচে পেস্ট করুন
৫. OBS দিয়ে স্ক্রিন ক্যাপচার করে সম্প্রচার করুন
Server URL: rtmp://a.rtmp.youtube.com/live2
📋 Facebook এ লাইভ করার ধাপসমূহ:
১. facebook.com/live/create এ যান
২. "লাইভ ভিডিও তৈরি করুন" → "Stream Key ব্যবহার করুন"
৩. Stream Key কপি করুন → নিচে পেস্ট করুন
Server URL: rtmps://live-api-s.facebook.com:443/rtmp/
🎬 OBS দিয়ে এই পেজ লাইভ করুন (ফ্রি):

১. OBS ডাউনলোড: obsproject.com

২. Source যোগ করুন: Sources → + → Browser
  URL: এই পেজের URL | Width: 1280 | Height: 720

৩. Settings → Stream → Service → Stream Key পেস্ট করুন

৪. "Start Streaming" চাপুন ✅
